# Garbled

A say-it-out-loud party game for phones. Read the gibberish on the card out loud, and your team works out the phrase it sounds like. Every card is original.

- **Party game:** 2–4 teams pass one phone around. Timed turns, limited skips, a hold-to-peek answer for the other team, and steals when time runs out.
- **Solo decode:** type what you hear. Ten cards per run, with hints that cost points.
- All sound effects are synthesised in the browser, so there are no audio files. It works offline once installed.

## Put it on your phone

The folder is a static site. With GitHub Pages switched on for this branch, it lives at
`https://dominichare.github.io/reportingtool/garbled/`.

- **iPhone:** open that address in Safari, tap **Share**, then **Add to Home Screen**.
- **Android:** open it in Chrome and tap **Install** on the menu screen (or ⋮ → **Add to Home screen**).

## Adding cards

Cards are in `index.html`, in the `RAW` object, one per line as `Gibberish|Real phrase`.
